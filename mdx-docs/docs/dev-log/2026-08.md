# August 2026
## diff view current file
LOL - i already had a binding for `<space>tg` to open diff view for current file.

So...
1. For bash, `--` is to tell the program "anything after this is a positional arg". like `rm -- -rf` actually *removes* a file called `-rf`
2. In neovim it means nothing, so using `--` in `DiffViewFileHistory` just... doesnt do anything and it ignores args afterwards, so `DiffViewFileHistory -- %` means the `%` does nothing


Correct is just `DiffViewFileHistory %`

> The one time is valid is where it's explicitly stated for this command `:DiffviewOpen [git rev] [options] [ -- {paths...}]`, see [here](https://github.com/sindrets/diffview.nvim)
