Like just getting a list of containers in json? Colleage says `docker ps --format {{json .}}`, as if adding `--json` was too hard for them ‍🤦‍♂️

quick refresher on how to use jq..
```bash
➜ jollof ~ jq '.[] | select(.role == "admin")' << EOF
[
  {"name": "Alice", "role": "admin"},
  {"name": "Bob", "role": "user"},
  {"name": "Charlie", "role": "admin"}
]
EOF
```
output:
```bash
{
  "name": "Alice",
  "role": "admin"
}
{
  "name": "Charlie",
  "role": "admin"
}
```

where we pipeline using a heredoc the multiline array into `jq` as as stdin and use the `select` to query the 2 rows with `role` as `admin`


ok - simply does it - now if we search for names with the letter `i` in them?
```bash
➜ jollof ~ jq '.[] | select(.name | test("i"))' <<EOF
[
  {"name": "Alice", "role": "admin"},
  {"name": "Bob", "role": "user"},
  {"name": "Charlie", "role": "admin"}
]
EOF

```
outputs:
```bash
{
  "name": "Alice",
  "role": "admin"
}
{
  "name": "Charlie",
  "role": "admin"
}
```

nice!

## Nvim refresher (magic mode etc)
gosh. ok so magic mode... the deafult is on
```vim
:set magic
```
return `magic`


according to colleague, `very magic` and `very nomagic` are later developments hence not having a setting 🤦‍♂️

e.g. in plain terms the default is as if we just did to substitute `:s/\m` every time for `\m` magic

now.... back to the example at hand... i wanted to delete everything up to the first literal ". so `[]` groups ARE default in magic mode, but `+` STILL must be ecsaped. thus it must be:
```
:%s/[^"]\+//
```
